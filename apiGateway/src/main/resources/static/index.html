Ближайшие дни рождения

Отсортировано по ближайшей дате среди друзей и участников ваших групп.

Подготовка поздравления

Все важное рядом: дата, wishlist, бронь подарка и секретный чат для плана.

1. Откройте карточку Выберите друга из ближайших дат или из списка друзей.
2. Забронируйте подарок Занятые идеи видны всем участникам подготовки.
3. Обсудите детали Сообщения в секретном чате приходят сразу, без перезагрузки.
